
## Unzip the dataset in here 

The project includes the 2024 SAMHSA MH-CLD source archive in:

`data/raw/MH-CLD-2024-DS0001-bndl-data-csv_v1.zip`

Extract the ZIP file inside `data/raw/`.

No files need to be renamed or moved. The Bronze script searches recursively for CSV files within `data/raw/`.
